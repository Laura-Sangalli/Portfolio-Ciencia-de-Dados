# Olá, seja bem-vindo(a)!

Este repositório reúne o meu portfólio em Ciência de Dados.

Comecei a estudar a área de Dados em janeiro de 2024, quando aprofundei meus conhecimentos em Python com foco em aplicações voltadas para esse campo. Desde o início, meu objetivo foi me tornar cientista de dados. No entanto, devido às demandas da minha formação acadêmica, interrompi temporariamente os estudos diretamente relacionados à área.

Ainda assim, não me afastei completamente: nesse período, dediquei-me ao desenvolvimento de pesquisas acadêmicas em Processamento de Sinais e Imagens, além da aplicação e adaptação de técnicas de Aprendizado de Máquina para esses contextos. Essa experiência contribuiu significativamente para o aprimoramento das minhas habilidades de programação e, principalmente, do meu pensamento analítico.
